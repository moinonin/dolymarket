# Prices & Order Book
Copy pageCopy page
Understand how prices are formed in Event Contracts and how the CLOB supports peer-to-peer trading.
Copy pageCopy page
Event Contracts use a Central Limit Order Book (CLOB). Prices are not set directly by the platform; they are formed by supply and demand between users placing buy and sell orders. ![Image](https://mintcdn.com/dexbuilder/HmQKrNhFx36mwspk/images/image-2.png?fit=max&auto=format&n=HmQKrNhFx36mwspk&q=85&s=6dfc5307fb45d09908317e5c17aa7c85)
## 
[​](https://dexbuilder.mintlify.site/en/event-contracts/prices-orderbook#price-represents-probability)
Price Represents Probability
Each outcome share is priced between `$0.00` and `$1.00`, which can be interpreted directly as the market’s estimated probability of that outcome. The displayed price is typically the midpoint between the best bid and best ask. When the bid-ask spread is too wide, the most recent trade price may be used instead.  
| Price  | Implied Probability  |  
| --- | --- |  
| `$0.25`  | 25%  |  
| `$0.50`  | 50%  |  
| `$0.75`  | 75%  |  
### 
[​](https://dexbuilder.mintlify.site/en/event-contracts/prices-orderbook#example)
Example
If the best bid for Yes is `$0.34` and the best ask is `$0.40`:

```
Displayed Price = ($0.34 + $0.40) / 2 = $0.37
Implied probability ≈ 37%

```

## 
[​](https://dexbuilder.mintlify.site/en/event-contracts/prices-orderbook#order-book)
Order Book
The order book contains all currently unfilled buy and sell orders for the Market:  
| Side  | Description  |  
| --- | --- |  
| Bids  | Buy orders showing the prices buyers are willing to pay, with the highest bid first  |  
| Asks  | Sell orders showing the prices sellers are willing to accept, with the lowest ask first  |  
The difference between the best bid and best ask is called the Spread. A narrower spread generally indicates better market liquidity.
## 
[​](https://dexbuilder.mintlify.site/en/event-contracts/prices-orderbook#order-types)
Order Types
### 
[​](https://dexbuilder.mintlify.site/en/event-contracts/prices-orderbook#market-style-trading)
Market-Style Trading
When you want immediate execution, you can submit an order that directly consumes available order-book liquidity:
  * Buy: begins filling against the lowest available ask.
  * Sell: begins filling against the highest available bid.


### 
[​](https://dexbuilder.mintlify.site/en/event-contracts/prices-orderbook#limit-orders)
Limit Orders
A limit order only executes at the specified price or a better price:
  * the unfilled portion remains on the order book;
  * a single order can be partially filled multiple times;
  * the unfilled remainder can be cancelled when cancellation is allowed.


## 
[​](https://dexbuilder.mintlify.site/en/event-contracts/prices-orderbook#matching-and-settlement)
Matching and Settlement
The Event Contracts CLOB uses a hybrid architecture:
  1. **Off-chain matching** : the matching service matches orders whose prices and quantities satisfy execution conditions.
  2. **On-chain settlement** : matched trades settle asset delivery through smart contracts.

This model combines the efficiency of off-chain matching with the verifiability of on-chain asset settlement.
