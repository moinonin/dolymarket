# Do's and don'ts

## Do
- Use limit orders with post-only when providing liquidity.
- Set a price you believe is below the true probability before buying.
- Cancel stale orders; capital is locked while they rest.
- Diversify across uncorrelated markets.
- Read the fee formula before high-frequency trading.
- Use idempotency keys for algorithmic retries.

## Don't
- Don't chase a price that has already moved.
- Don't size a single position beyond your risk budget.
- Don't assume past desk performance predicts future results.
- Don't share API keys or passkeys.
- Don't treat this simulation as financial advice or a regulated exchange.
