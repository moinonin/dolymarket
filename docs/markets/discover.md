# Discover markets

Browse **Live Markets** for real-time global markets, or switch to the **Community** sub-tab (**Live Markets → Community**) for local and user-created binary markets.

- Filter by category (`Politics`, `Crypto`, `Sports`, `Macro`, `Pop Culture`, `Tech`) and status (`All`, `Active`, `Ending Soon`, `Resolved`).
- Sort by volume, liquidity, newest, or ending soonest.
- Click any card to view probabilities, order book depth, and place trades.
